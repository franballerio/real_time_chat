1. Migrate Database to PostgreSQL
   * Goal: Move from JSON/file storage to PostgreSQL for reliability and scalability.
   * Steps:
       1. Add PostgreSQL driver and migration tool (e.g., `pg` + `knex` or `prisma`) [x]
       2. Design schema:
          - users (id, username, password_hash, role, created_at)
          - rooms (id, name, type, created_by, created_at)
          - room_members (room_id, user_id, joined_at)
          - messages (id, room_id, sender_id, body, created_at) [x]
       3. Create initial migrations and indexes (room_id, created_at, sender_id) [ ]
       4. Implement repository/data-access layer for users, rooms, messages [ ]
       5. Build one-time migration script from JSON data to PostgreSQL [ ]
       6. Enable transactional writes for message + audit operations [ ]
       7. Add backup/restore strategy and connection pooling config [ ]

2. Integrate RabbitMQ (Production-Ready)
   * Goal: Decouple messaging from Socket.IO and make delivery resilient under load.
   * Steps:
       1. Add `amqplib` and create a dedicated messaging module [ ]
       2. Define topology:
          - exchange: `chat.events` (topic, durable)
          - queues: `chat.message.persist`, `chat.message.broadcast`
          - routing keys: `chat.room.<roomId>`, `chat.broadcast`
       3. Publish from API/socket layer with persistent messages and correlation ids [ ]
       4. Add consumer workers with manual ack/nack and retry strategy [ ]
       5. Configure dead-letter queue (DLQ) for failed messages [ ]
       6. Add idempotency key check to avoid duplicate processing [ ]
       7. Add reconnect/health-check logic and metrics for queue lag [ ]

3. Integrate Redis (Caching + Session + Presence)
   * Goal: Improve latency and support scalable session/presence management.

       2. Store sessions and token metadata in Redis [ ]
       3. Cache recent room messages (TTL) for fast initial load [ ]
       4. Track online users and room presence using Redis sets [ ]
       5. Use Redis pub/sub for multi-instance Socket.IO scaling [ ]
